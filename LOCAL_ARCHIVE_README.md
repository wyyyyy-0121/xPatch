# Local source and paper archive — 2026-11-17

This branch preserves the local xPatch/RV30 source history, the current AAPL multiscale source, unique experiment implementations and current paper files before the user-requested local project removal.

- `aapl-research/`: current multiscale source and one copy of each distinct experiment source file. Files retained below `outputs/` are selected source files only.
- `papers/aapl-multiscale-20261111/`: current six-page paper PDF, LaTeX source, figures, figure inputs and supplements.
- `research/paper/`: existing RV30 working manuscript, Word/LaTeX files, figures and source notes. These remain working research documents, not publication acceptance.
- `SOURCE_ARCHIVE_MANIFEST.json`: retained source/paper identities and mappings from duplicate source paths to the retained copy.

Raw market data, sealed holdouts, trained model checkpoints, predictions, full experiment outputs, credentials, package caches and virtual environments are excluded. The repository is a source/paper archive and does not contain a complete reproduction or trained-model deployment bundle. Existing old data already present in the main branch history are not expanded by this archive. Some historical documentation refers to local artifacts that are intentionally absent after the user's cleanup request. Re-running training or verification requires obtaining the applicable inputs and weights again.

No claim of live profitability or completed prospective validation is implied by preserving these files.
