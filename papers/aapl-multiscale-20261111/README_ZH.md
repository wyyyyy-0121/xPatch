# AAPL 六页英文双列论文：正文与图表修订版

主文件为 **main.tex**，预览为 **main.pdf**。全文包含标题、作者、摘要、正文及参考文献，共 **6 页**，A4 双列，正文 10pt。题目、Wang Yang 署名及学校信息沿用上一版；邮箱留给作者填写。

本项目采用通用 article 版式。收到具体会议或期刊的官方模板后，还需要套用其格式并重新核对页数。

## 本次修改

正文从“实验进度汇报”改为围绕结果展开的论证：初始化为何能大幅降低默认模型误差、这些降低为何尚不足以超越简单预测，以及年度和月度结果分别受到什么影响。合并重复的限制说明，删去内部阶段账目和交付状态，把不成功的尝试压缩到一个小节，完整记录仍在补充材料中。

四图全部重画，分别承担不同任务：

1. **干预矩阵**：交叉展示初始化和价格锚点，以相同色阶显示两项收益任务的误差。
2. **对数点图**：对比延长默认训练与改变初始化，直接标出数值及持有不变的参考线。
3. **年度区间图**：展示两种区块长度下的完整历史区间，区分持有不变／零收益与历史均值两个参考。
4. **拆股事件时间线**：标明 2020 年公告、保守信息可用边界和生效日期，连接名义预测目标与参考误差变化。

三张表保留任务定义、全部二十项预测结果和概率筛查结果。新增的平方误差解释、拆股与财富收益的区别均服务于已有结果；本版没有新增实验或重算区间。

## 编译

将整个项目上传到 Overleaf，以 `main.tex` 为主文件，选择 pdfLaTeX。图片和参考文献已包含，无需运行 Python 或 BibTeX。

本地可运行：

```bash
bash build.sh
```

或者手动运行两遍：

```bash
pdflatex -interaction=nonstopmode -halt-on-error main.tex
pdflatex -interaction=nonstopmode -halt-on-error main.tex
```

在 `main.tex` 中修改 `\emailaddress` 即可填写投稿邮箱。
