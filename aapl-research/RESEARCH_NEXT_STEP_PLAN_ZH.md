## 2. 研究问题与唯一设计

问题：在原分钟 H60、小时 H8 两项任务上，保持收益中心预测为零，仅利用已经完成的历史价格和交易日历，能否较稳定地预测未来收益分布的尺度？日内时钟及跨交易日标签是否提供超出简单波动模型的增量？

主要预测对象仍是原累计对数收益 y(t,H)=log(P(t+H)/P(t))。**未来累计收益的平方与未来逐步收益平方之和不同**：后者可以作为历史特征的参照，但不能偷换评分标签。

唯一候选 C 是一个小型条件尺度模型，不新增神经网络或专家融合：

    y(t,H) | history ~ Student-t(df=5, location=0, scale=s(t,H))
    v(t,H) = exp(b0 + b_s*z_short + b_d*z_day + b_l*z_long
                      + c1*sin(2*pi*u) + c2*cos(2*pi*u)
                      + d*n_gap)
    s(t,H)^2 = v(t,H) * (5-2)/5

其中 v 表示分布方差；t 分布 scale 与标准差严格区分。z 是仅由训练前缀确定尺度的历史对数平方收益统计：最近 H 个原频率增量、最近一个完整交易日、最近二十个完整交易日。u 是最近完成 bar 在常规交易时段中的位置；n_gap 由当时已知的交易日历计算，为预测路径跨交易日边界的次数。分钟 H60 原规则不跨日，n_gap 恒为零，该项不拟合、不声称识别跨夜作用。

历史收益增量、缺失 bar、日界、拆股处理、小时残段及特征支持域必须在读取本轮评分结果前写入执行协议。历史统计使用已完成价格，不使用未来方差或预测路径实现的波动。历史增量的平方和只作为输入，不宣称它无偏估计未来累计收益方差。

候选最多七个自由系数，每个任务、每折独立拟合。固定 df=5、固定同一优化规则和标准化后非截距 L2 惩罚 0.01；不搜索分布族、自由度、特征窗口或正则强度。拟合目标为前缀平均负对数似然加惩罚。优化失败或方差数值资格失败则停止该配方，不在看到分数后更换设置。

这是一项简单模型及机制消融研究；目前不声称模型结构原创，也不保证相对经典波动模型有优势。实现阶段须核读并引用 EWMA、HAR 及 Student-t 金融收益建模的原始来源，不能把这段设计说明当成已有文献验证。

## 3. 固定对照与工作量

所有概率对照保持同一零中心和 df=5；只比较尺度预测。否则，分布族或均值的变化可能被错算成方差模型贡献。

| 配方 | 做法 | 回答的问题 |
| --- | --- | --- |
| B0 | 仅用训练前缀拟合常数尺度 | 条件尺度是否优于无条件分布 |
| B1 | EWMA 单步平方收益，固定衰减 0.94；H 倍转换后，仅在训练前缀拟合一个正比例校准量 | 是否优于简单随时间变化的波动参考 |
| B2 | C 的三个历史波动输入，移除时钟与跨日项 | 是否优于同信息 HAR 型小模型；不称标准日频 HAR 的逐字复现 |
| C | 历史波动＋日内时钟＋已知跨日项 | 唯一候选是否有增量 |
| A_clock | C 去掉日内时钟项 | 增量能否由时钟项的配对消融支持 |
| A_gap | C 去掉跨日项 | 小时跨日项是否有增量；分钟与 C 完全重复，直接复用 |

最多：2 个任务 × 5 折 × 6 个配方 = **60 个拟合位置**，重复配方按身份复用，不为填满数量重复计算。先完成前两原折，最多 24 个位置；只有通过预定筛查，才完成剩余三折、最多 36 个位置。没有随机网络初始化，不机械增加三组随机种子。

每个配方至少做一次同输入确定性重放，检查保存参数、预测、似然和分位数能否重建；这属于数值复核，不计作新市场样本。

## 5. 指标与事前停止规则

主要指标是累计收益的平均负对数似然 NLL，单位 nat／origin，越低越好。辅助报告 CRPS、50%／90% 区间覆盖率、平均区间宽度及 PIT。不能单靠放宽区间声称预测成功。CRPS 采用同一冻结的确定性计算程序；先在已知分布与独立计算中通过数值资格，不能在看到结果后更换实现。

所有主要相对改善为逐 origin 的配对差；不能把不同收益单位的原始损失直接平均。区间覆盖与宽度按期限、折和已知跨日状态报告，不根据结果再切有利子组。

### 前两折筛查

两项任务分别判断。C 必须在两个原折都具有低于 B0、B1 的 NLL，且合并后相对二者均至少降低 **0.01 nat／origin**；对 B2 的合并 NLL 不得更差。任一原主要任务不满足，就停止本轮候选扩展，不跑剩余三折，不换配方救结果。

0.01 nat 是事前选择的最小实际效应门槛，不是由历史分数拟合，也不宣称具有通用经济意义。筛查结果不算确认，筛查不使用显著性保证。

### 完整五折开发验收

只有筛查通过才执行。每个任务必须同时满足：

1. 相对 B0、B1、B2，C 的五折合并 NLL 分别至少降低 0.01 nat／origin。
2. 对每个上述基准，至少四个折的 NLL 配对改善为正。
3. 对每个上述基准，在原两种块长度下，配对 NLL 改善的名义 95% 区间下界都大于零。折独立作为 bootstrap strata，重复 5,000 次，固定随机种子 2026。分钟用一／五交易日，小时用二／五交易日。
4. C 的合并 CRPS 不高于各基准的 1.01 倍，50% 与 90% 区间的合并覆盖分别落在 [47%,53%] 与 [87%,93%]。这些为事前容忍带；同时报告块区间及有效样本，不将落带等同精确校准证明。

只有这些门都通过，才能写“该任务有合格的历史开发增益”。两任务都通过才能作两期限共同结论。不能凭本轮名义区间声称经过多次历史研究后仍保持原始错误率，亦不能据此替代未见确认。

只有 C 相对相关消融也有两种块区间支持时，才把增量归于该项的**算法配对干预**。恒零、共线或缺乏状态变化的项不作机制解释；即使有改善，也不据此认定经济因果。若 C 只胜 B0、未胜 B1/B2，就报告条件尺度有信号但新候选没有超越强参考。

## 8. 预期成果与论文落点

最理想的可检验成果：原收益中心难以改善，但一个已冻结的极小尺度模型在原两期限的概率评分和校准上得到稳定开发改善，且消融支持具体信息项的增量。通过后仍需未见确认，才有更强结论。

次一级成果：经典 EWMA/HAR 型参考明显优于常数分布，候选 C 没有额外优势。此时写清可预测对象的差异，不制造“原创小模型成功”的说法。

负面成果：条件尺度也未达到门槛，或数值/支持域资格失败。保留合格结果、失败类型和复现材料；不换分布族、阈值或期限继续寻找胜者。原已验收的聚焦版论文仍可使用，失败补充不占主稿中心。

论文原题、五尺度二十任务以及初始化修复主线保留。若本概率扩展获接受且有结果，仅作为两个短期限的额外研究问题；不得把长尺度也写成已完成概率实验。原均值方法的成功缺口持续单列，**概率改善、数值验收、文稿交付和原科学 Goal 完成是四件事。** 论文接受发表的把握不能从本计划推断。
