# AAPL 多尺度研究：当前实现与边界

这是独立于原十二分钟冻结研究的工作目录。五个尺度、十个跨度、价格与累计 log 收益两类目标见 `spec.py`。截止 2026-11-07，本目录完成数据与工程准备的一部分；**没有完成多尺度正式实验，也没有预测效果结论**。

## 已实现

- `bars.py`：重新核验原 SIP 分钟数据身份，生成完整小时柱；逐点价格和累计收益路径、同日分钟标签、缺失窗口排除。
- `admission_alpaca.py`：基于已有账户的 Alpaca SIP/raw 日线和分钟来源，生成二十个候选任务、五折起点与旧测试台账重叠记录。它不读取 Q3 市场数据，不生成预测分数。
- `exposure.py`：只读旧测试使用台账，按日期合并已曝光区间；不重新读取旧测试得分。
- `features.py`、`baselines.py`、`ridge.py`、`models.py`：共享 close 历史、三个无训练基线、流式 Ridge、MLP、GRU、LSTM 和原生 xPatch backbone 的任务适配。
- `splits.py`、`training.py`：按真实标签完成时间隔离外层和内层；标准化只拟合内层训练数据；检查点保存模型、优化器、采样顺序与随机数。
- `mechanism.py`：预设等权共享跨度路径损失，已用合成数据测试；配对实验仍未执行，必须使用相同 H60 起点和隔离边界。
- `development.py`：单折八模型开发流程；在所有模型训练和内层选择结束后才提取外层标签评分。折级状态支持进程锁、已完成阶段校验、检查点接续和不覆盖不完整尝试；当前只用合成数据验证，不是正式比较。数据身份哈希覆盖完整柱数组，但不参与模型更新或选择。意外终止时持久化的运行时长可能少计中断前工作，成本须结合外部进程记录核算。
- `protocol_draft.py`：生成不可运行的二十任务清单和更新次数上限；草案不能被当成协议冻结或计算授权。
- `matrix_plan.py`：只读取候选准入回执元数据，列出二十任务、100 个候选五折任务、八模型槽位及逐项障碍；输出始终不可运行，且不读取行情数组。
- `matrix_gate.py`、`matrix_executor.py`：检查绑定数据身份的权利、质量、曝光、计算预算和冻结协议，按一个设备队列执行、独立复算并在折边界接续。若某尺度尚不能准入，可在评分前按完整尺度冻结部分矩阵并记录所有遗漏；当前没有通过正式准入。门控只核对人工复核记录及证据字节，不自动判断法律含义。新云端资源必须有明确授权，程序不会租赁机器。
- `matrix_selftest.py`：构造清楚标记的虚构数据与虚构复核记录，验证完整与部分矩阵的冻结、队列暂停和接续；所有输出与真实研究分开，不代表正式运行或发表许可。
- `aggregate_development.py`：独立核对已保存折并按起点数合并全路径／终点误差，使用冻结的交易会话分块计算描述性区间，并做年度非重叠起点敏感性；不输出开发阶段 p 值。默认要求五折齐全，显式请求部分汇总时会列出缺失折。
- `gpu_recovery_check.py`：仅用合成价格，在独立进程中于 xPatch 更新后退出并恢复，比较完整折与不中断参照。它不读取市场数据，不能代替正式吞吐准入或论文结果。
- `evaluation.py`：逐步/路径/终点指标、按时间块重采样和 Holm 校正工具；是否可做独立检验仍取决于真实确认数据。
- `verify_development.py`：独立重算已保存开发折的八模型指标，核对预测起点、目标时间、权重和相关文件哈希；不替代数据来源、许可或独立评价。
- `acquire_kaggle_candidate.py`、`audit_kaggle_candidates.py`、`audit_alpha_candidates.py`、`audit_sec_ranges.py`、`audit_plotly_reference.py`：受截止日期限制的候选来源与公司公告交叉诊断，不构成数据准入或模型评分。
- `acquire_kibot_candidate.py`、`audit_kibot_candidate.py`：通过官方公开访客接口获取截止日期内日线并仅在本机核查来源及价格口径；发表权和早期价格口径未确认，数据不用于训练。源数据及派生诊断只留在忽略目录。
- `benchmark_matrix_synthetic.py`：对五尺度四种神经模型运行受限合成吞吐测量，包含验证与检查点写入；合成价格和本机速度不能证明正式训练收敛、真实数据 I/O 或云端速度。
- `benchmark_projection.py`：依据合成测量和候选矩阵做有明确遗漏项的时间示例，不构成预算批准或运行保证。
- `coverage_alpha_dates.py`：用候选日期并集和人工常数价格估算年度／季度起点与折数；不拼接真实行情、不训练、不冻结协议。
- `smoke.py`、`benchmark_local.py`：只作受限本机工程检查，不选择模型或作为预测效果证据。

原生 xPatch 的网络输出包含半长度池化，无法直接设置 H=1。本实现用原生 H=2 输出头取第一步，并增加当前价格锚点线性读出；这两项是任务适配，必须与原论文配置区分，不能声称完全复现原文实验。

输入窗口只调整预测时点之前已经生效的拆股，以消除已知历史股数变化；实际未来价格与收益标签采用名义收盘价。跨未来拆股的标签会包含名义价格变化，需单独报告敏感性；不会将未来拆股信息当输入。外部供应商的回溯调整收盘价和调整成交量不用于当前模型。

分钟标签限制在同一常规交易日；小时柱从 09:30 ET 开始，每柱完整 60 分钟，末尾不足一小时的部分不冒充完整柱，小时预测可跨交易日。日线按纽约自然日结束后的午夜作为保守的最早完成时间；2026-06-30 日柱的最终完成时间越过当前截止，不能用于本轮标签。历史最终数据仍不证明当时的真实发布和修订时点。

## 数据与证据状态

- 已有账户的 Alpaca 日线实际返回 2016-01-04 至 2026-06-30，年度低于原定十五年最低历史；季度第一折的内层拟合只有个位数起点，需在任何外层评分前处理并记录。其他尺度也只是候选。
- 季度另有未冻结的五折候选：仅根据样本数将首折内层拟合起点提高至 24 个，每折保留至少六个月验证。此规则没有参考模型分数；24 个起点仍很少，不能当作充分训练或统计效力的证明。
- EODHD 的长期数据覆盖更早，但其个人用途条款和学术研究许可需要区分。**在学术使用及发表权利核实前，不把演示接口数据用于训练或论文结果。** `admission.py` 的长期供应商入口暂停；既有诊断输出留在忽略目录作记录。
- 三份 Kaggle 候选均标注 CC0，其中两份重合的 10,486 个日收盘价完全相同；上传者的标签不证明上游来源或权利。第三份候选的 1999–2000 财年季度高低范围与苹果 SEC 年报对齐到 1 美分内，但这不证明全部历史收盘价或复权链。完整来源状态见 `DATA_SOURCE_REVIEW.md`。
- 另有两份上传者归因于 Alpha Vantage 的 1999–2024 年候选，重合日期的收盘价完全相同；其中一个 2015 年月末值与其他诊断来源有约 0.318% 的差异。来源许可与差异处理均未冻结。
- 2026-11-07 查阅供应商网页时研究者意外看到一条当前 AAPL 报价，报价生效时间未核实；该报价未进入数据、训练或评分，也没有请求 Q3 逐日行情。不能因此声称完全未接触截止后信息；任何封存期独立性判断前须审计，记录见 `DATA_SOURCE_REVIEW.md` 和本机 `outputs/multiscale/POST_CUTOFF_EXPOSURE.md`。
- 2014 至 2022 年旧测试使用台账已有曝光记录；原 2026Q3 仍为封存段。以前的开发、校准或测试数据不因换模型或来源变成独立确认。
- 供应商日线与分钟最后一根柱的收盘价定义不同；两者价格差异不能直接断言哪一家错误。日线发布时点、历史修订和论文发表/再分发权利仍需核查。

## 已执行的工程检查

在本机 RTX 5070 Ti Laptop GPU 上，二十个任务形状的八类模型接口已跑通，四类神经模型共完成 80 次小批量更新；日线/月线使用合成价格，分钟/小时使用此前已准入来源的开发数据。H60/L480、batch 128 的短测使用 32,768 个内层训练起点、一个等价轮；xPatch 在第 3 次更新后从独立进程恢复，与不中断运行的模型、优化器及内层训练记录一致。

这些检查不评估预测优势。短测时间只有数秒，不能证明训练充分、推算云端 5090 耗时或替代计划中的完整云端准入。之后已在 RTX 5070 Ti Laptop、PyTorch 2.14.1+cu130 上，使用当前版本和合成价格复核 GPU 折级恢复：xPatch 第三次更新后进程退出，新进程恢复；八模型预测和指标与不中断运行逐值一致，四个神经模型的最终检查点、优化器和随机状态一致，两份折回执均通过独立复算。回执位于本机 `outputs/multiscale/gpu_recovery/20261107T071519095622Z/`。这只是小规模合成工程验证，正式完整包及真实独立测试尚未执行。

候选 Alpaca 清单目前形成 100 个五折任务，其中年度十折任务不满足原定最低历史要求，季度两个首折任务内层拟合少于八个起点；其他折也未通过共同数据权利、协议和预算门控。按每种神经模型最多 20 轮、batch 128、一种子估算，整个候选矩阵最多 5,368,800 次神经更新；八模型预测值按 float64 的未压缩载荷约 5.211 GiB，不含标签、索引、模型、重试和压缩影响。这不是计算时长或磁盘峰值的结论。清单位于本机 `outputs/multiscale/matrix_plans/20261107T072106234518Z/`。

2026-11-07 的本机合成吞吐测试持续约 915 秒，覆盖五尺度、四种神经模型共 20 种形状；分钟最大形状按候选第五折规模生成合成输入，并包含验证、预测、检查点和压缩写入。基于候选矩阵、每模型至多 20 轮、一种子，按各形状实测的中位数与第 90 百分位计算并乘以 1.3，示例分别约 **15.62 和 16.51 小时**。这不是置信区间或时间保证，未计真实数据读取、Ridge、基线、完整评分、复核、异常重跑、额外种子与机制实验；长期来源改变后年度折数和样本也会改变。本机短测不能外推到云端 5090。该次测量未在启动时记录代码哈希；后补源文件快照不能证明进程当时执行的字节，因此正式准入前还需用已固定代码重新短测。回执与计算分别在 `outputs/multiscale/synthetic_matrix_benchmark/20261107T073050865411Z/` 和 `outputs/multiscale/benchmark_projections/20261107T080711941729Z.json`。

当前队列的正式能力边界：同一个本机设备由文件锁串行调度，已完成折会复核哈希和指标，预算到期会停止当前进程并保留已有检查点；若尚未写出检查点则保留不完整尝试。意外退出后的耗时按保守方式恢复。不同机器不共享全局任务锁，不能据此保证跨云端不重复；改变数据、代码、复核或预算身份后不会自动续跑。完整与部分矩阵分别经合成队列检查，单折经进程中断测试，尚未进行完整 100 折的异常恢复演练。门控也不能自动证明人工选择没有受到此前分数影响，后续冻结仍须审计曝光。

## 本机测试

从 `aapl-research` 目录执行：

```bash
mkdir -p tmp
AAPL_TEST_DIR="$(mktemp -d "$PWD/tmp/multiscale-pytest.XXXXXXXX")"
AAPL_CPU_IDS='0-11,14-17' AAPL_CPU_THREADS=2 bash scripts/python.sh -m pytest -q \
  --basetemp "$AAPL_TEST_DIR/run" tests/test_core.py multiscale/test_foundations.py \
  multiscale/test_kibot_candidate.py multiscale/test_matrix_plan.py \
  multiscale/test_matrix_gate.py multiscale/test_matrix_executor.py multiscale/test_aggregate_development.py
```

以上 CPU 亲和性避开现有原任务预留的 12、13 号逻辑核心。每次使用新的测试目录，避免 pytest 默认轮换已有 `tmp/pytest-of-ayaka` 会话；新目录保留供用户决定是否清理。市场数据、权重、预测、供应商原始响应和机器收据均在 `outputs/` 忽略目录，不提交 Git。

下一步是取得供应商对本项论文使用的书面说明，处理长期候选的价格口径和季度早折样本，随后冻结数据、跨度、预处理和有限训练矩阵；先短测再决定正式计算。不因旧模型工程验收通过而宣称新模型完成。

复核记录与配方均保留为不可运行草案，字段和执行限制见 `ADMISSION_GATE.md`。当前不能把草案或合成自测中的虚构复核记录用于市场数据。

候选矩阵清单可用以下命令重新生成；它不会启动训练：

```bash
AAPL_CPU_IDS='0-11,14-17' AAPL_CPU_THREADS=2 bash scripts/python.sh -m multiscale.matrix_plan \
  --admission outputs/multiscale/admission/alpaca_20261107T052228573242Z
```
