## 当前实现实际改变了什么

以下以当前源代码为依据，区分架构复用、任务适配和待验证假设。

| 组件 | 实际实现 | 可支持的表述与限制 |
| --- | --- | --- |
| xPatch/PatchTST 监督专家 | `fusion/next/expert_models.py` 将本地和市场历史通道送入原生 backbone，用线性输出及股票嵌入生成 12 步收益，再求和 | 是针对本任务的监督适配。输入、输出、损失与原长跨度通用 benchmark 不同，不称为原论文数字的直接复现 |
| 融合的本地支路 | `fusion/next/models.py` 的 `LocalBranch` 复用 xPatch Network，以 EMA 分解后输出经学习投影 | 是借用已有架构提取局部特征；原生 xPatch arctangent loss 与 sigmoid 调度未因此自动被使用 |
| Chronos 表示 | 同一 `FoundationBranch` 对每个起点内部三路历史使用 group attention，再对变量表示池化、学习投影 | 本轮是冻结表示加监督头或 LoRA 适配，不是原生 zero-shot 点预测；group ID 按起点区分，跨起点共享不属于该实现 |
| 状态门控 | 四个固定专家与零收益组成五个 softmax 权重，另有 sigmoid 收缩及受过去波动约束的残差 | 门控、收缩和残差分别是已有思想；需要与简单融合、特征拼接及去基础支路结果比较才能判断本组合是否有增量 |
| LoRA | 只向 Chronos 注意力 q/k/v/o 附加低秩更新；主骨干冻结，投影和融合部分另行训练 | 报告总参数、可训练参数、rank 和计算成本；本轮冻结/LoRA 对照检验适配效果，不证明 LoRA 方法创新 |
| 专家融合训练 | 13 季度向前 OOF，评价折之前的合法专家输出用于拟合融合；早期无 OOF 历史使用另设辅助读出 | 实现时间隔离的 stacking；已选专家超参和开发数据的已知性仍需披露，不能把 OOF 自动等同于完全未选择的独立检验 |
| 11/8 的 raw/scaled 比较 | `trainer.loss_for` 中 raw 用训练段固定单位缩放，scaled 用过去波动缩放，主评分统一原始收益 MSE | 固定单位只对预测误差项作常数缩放；门控平滑正则仍存在。该试验比较完整训练目标，不能把差异全部归因为样本权重或纯粹的统计效率 |

模型锁固定 `amazon/chronos-2` 的 revision `29ec3766d36d6f73f0696f85560a422f50e8498c`。已有 [模型可用时间核查](model_availability.json) 记录发布/仓库时间与保存的 checkpoint 元数据，且明确 `pretraining_sample_boundary_independently_verified=false`。本次尝试实时刷新 Hugging Face 元数据超时，未把旧记录升级为实时确认。2025 年较早的验证季度不能被描述为当时可部署该公开 checkpoint 的交易回测；这与本项目训练/评价时的时间隔离是两个不同问题。

## 本次固定试验能回答的问题

原研究在三个开发季度和三种子下比较监督专家、简单融合、冻结融合、LoRA 及特征拼接。100 小时修订明确递延了若干机制；没有执行独立迁移、随机骨干和去市场对照，就不支持相应独立归因。

11/8 的固定 2×2 矩阵继续以原选中冻结结构为参照：有/无 Chronos 支路，scaled/raw 训练目标。pilot 是三个新配方各三个季度、seed 2026 和两等价轮；补种子仅按已有探索条件和固定配对关系执行。它可以检查开发数据上的训练目标差异、去支路差异及两者交互。移除支路同时改变参数量和初始化，描述性差值不能直接写成预训练的独立因果作用。

所有比较保留零收益、固定最强单模型和简单融合；三种子均值系统与单种子结果分开报告。CPU 包验收回答能否稳定重放、恢复和满足部署延迟，不能替代预测增量证据。已用于开发的后续结果仍需另定的独立未来数据支持最终研究主张。
