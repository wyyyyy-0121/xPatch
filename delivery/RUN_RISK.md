## 实测性能

新实现将 DEMA 前向及其反向递推分别融合为 GPU 内核，严格保留原 float32 运算和梯度累加顺序；禁用 FMA，保留影响 RevIN 参数归约的梯度布局。训练数据在显存准入通过时预载，批次顺序、值和 stride 与原路径相同。数据副本最多 1 GiB，并要求复制后至少留 1 GiB 空闲；准入失败或复制遇到 OOM 时使用原数据路径。

以下最大规模测试仅复制 2023 年以前的起点，不进入正式调参或评价。原生和 CUDA graph 数据来自上一轮固定工作负载，本轮正式安装代码另行测量，数值与原生检查点及完整预测逐位比较通过。单次计时包含机器当时的运行噪声。

| 相同最大工作负载 | 最初原实现 | 上一轮 CUDA graph | 本轮正式安装实现 |
|---|---:|---:|---:|
| 72,397 样本，完整首轮，含初始化 | 60.55 秒 | 16.17 秒 | 9.06 秒 |
| 6,920 校准起点，完整预测 | 2.33 秒 | 0.71 秒 | 0.22 秒 |
| 86,306 评价起点，完整预测 | 30.91 秒 | 7.09 秒 | 2.47 秒 |

本轮正式安装首轮比最初快约 6.68 倍，比上一轮快约 1.78 倍。完整评价预测比最初快约 12.49 倍。候选实现最大规模 1→5→15→30 轮持续运行通过，最后 15 轮共 90.92 秒，平均约 6.06 秒/轮；该数值不包含首次编译和初始化，不能与含初始化的首轮混用。

四项真实早期数据任务包含不同 DEMA/EMA 配置的三轮训练、完整校准及评价：控制器计时由 39.77 秒降至 17.76 秒，约快 2.24 倍。任务内部耗时之和分别为 39.22 和 17.29 秒。不同配置收益不同，不将上述最大规模倍数当成整项搜索保证。

显存预载加前向融合的双 worker 对照为 34.05→33.46 秒，仅约 1.76% 吞吐改善；单任务变慢，内存开销增加，未启用正式并发。该对照发生在完整反向融合之前，不声称已经测试完整反向融合的双 worker。当前保持一个 GPU worker。

## 正确性、资源与恢复

32 配置 × 两个信息集 × 单例/部分/完整 batch，共 192 项输出、损失、梯度、更新及状态逐位检查通过。六组固定种子训练/续训、最大规模 30 轮检查点及完整预测逐位一致。正式安装代码另行通过两种 DEMA 与 EMA 对照的双向恢复、验证历史、优化器、RNG、保存模型预测及显存预载回退验证。工程检查共 119 项通过，包含完整 22 线程配置的子进程继承验证。

正式安装最大规模测量进程 RSS 峰值约 4.37 GiB，PyTorch 显存分配峰值约 0.74 GiB；它不包含桌面和驱动的整卡显存。该测试结束时 WSL 可用内存约 12.10 GiB。候选持续运行分配峰值约 0.75 GiB。工作站其他程序的后续占用仍会改变余量。

CPU 基线任务已经结束，暂停前 CPU 队列为零，余下工作集中在 GPU。22.59 秒被动采样里 Python 主线程用了约一个 CPU 核心，其余多数线程等待；GPU 大多为 83–88%，任务交接时下降。增加 BLAS 线程和两 worker 对照均未显示足以采用的吞吐收益。因此当前通过减少 GPU 递推与调用开销提速；保留全局最多 22 逻辑线程及低优先级，不为占用率增加无用任务。

原多 batch CUDA graph 的跨 stream 梯度累加同步警告仍保留在日志中；所有逐位检查和恢复均通过，未屏蔽警告。单次截图中的利用率不能独立证明进程故障或精确定位全部瓶颈。

## 中止风险

暂停前完成 9,786 个正式任务，失败数为零；最长已完成 xPatch 任务约 356.20 秒，冻结的单任务上限为 10,800 秒。暂停前 GPU 累计约 14.02/240 小时、CPU 分配约 73.01/2,000 核时、正式工件约 5.68/60 GiB。本轮整个受控验证区间按 22 个分配 CPU 和 GPU 墙钟保守计入同一预算，唯一收费项与实际恢复记录见 `delivery/amendments/fused_throughput.json`，续跑不清零预算。

| 风险 | 当前证据 | 执行规则 |
|---|---|---|
| 单任务超时 | 已完成任务离上限远，最大规模 30 轮通过；更大外部负载仍可能拖慢 | 保留超时及逐轮原子检查点，不静默删失败试验 |
| 内存/显存不足 | 已测最大规模有余量，截图时 Windows 内存已达 81% | 单 GPU worker、显存预载准入和原路径回退、内存调度门槛 |
| 总计算预算耗尽 | 当前远离冻结上限 | 全部诊断及中断计费，共享原 240 GPU 小时、2,000 核时和 60 GiB 上限 |
| 进程或系统中断 | 已验证双向恢复，检查点兼容 | 独占锁、PID 与启动时刻、同签名续跑；不据 stdout 安静重启 |
| 研究无稳定增益 | 性能数据不能估计其发生概率 | 完成原搜索与独立复核；未通过则完整交付 HAR 基线和阴性证据 |
