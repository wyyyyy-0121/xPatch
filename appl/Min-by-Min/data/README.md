# 数据清单与限制

实际文件范围、字段检查和 SHA-256 见 `inventory.json`。日线／月线缓存已放在本项目目录，运行不依赖 `/tmp`；新缓存 CSV 不上传 Git，按以下步骤复建。

| 文件 | 当前范围／来源 | 用途 |
|---|---|---|
| AAPL_1d.csv | 1980-12-12 至 2022-06-17，固定 GitHub 镜像，10,468 行 | 过期、未独立验证的工程回归；不能代表最新市场 |
| AAPL_1mo.csv | 从上述日线聚合，只保留完整 XNYS 交易月，497 行 | 同样仅为工程回归 |
| AAPL_1min.csv | 原仓库附带，2024-06-03 至 2025-06-06，242,612 行 | 时区、来源和复权未验证，真实小时／分钟实验禁止排名 |
| ../../archive.zip | 用户提供，2006–2024 年所谓分钟数据 | 审计为线性插值，拒绝训练；原文件不修改、不上传 |

优先用 `python download_data.py --symbol AAPL --interval 1d --refresh` 获取最新数据，再用 `--interval 1mo` 下载月线。本次 Yahoo 返回 HTTP 403，失败记录保留在 `AAPL_1d.download_failure.json`，没有把旧数据伪装成新数据。

复建与本次回归相同的旧缓存：

```bash
python prepare_regression_data.py
```

该入口固定镜像 commit `08ba60b568c300a635da1b6291a0f54eb9ef3f13`、原始和规范化 CSV 两种哈希，缺失／截断／变更会失败。它核实复现文件身份，**不等于核实原始行情、复权或来源可靠性**。下载网址、真实下载时间及旧数据限制保存在 sidecar。原 `/tmp` sidecar 的检索时间没有可靠证据，不继续当作真实检索记录。

分钟文件必须为一分钟 OHLCV、明确起始时间标记及 IANA 时区，正常交易分钟不应有日线级插值。覆盖率分母来自完整 XNYS 常规交易日历，含首尾全天和缺失整天；边界天不完整也应另行补全或明确裁剪。允许最多 2% 缺失并不意味着填补缺失：缺柱所在样本仍被排除。

`provenance.example.json` 仅是结构模板，无法直接通过验证。人工核实供应商原始文件、下载记录、时区、复权和时间标签后，凭证应记录真实 reviewer / source_url / review_evidence 与哈希。不要通过修改一个布尔值、来源文字或时区来“修复”无法验证的数据。
