`AAPL_clean_1min.csv` 来源页为 [HF Data Library](https://hfdatalibrary.com/pages/download?)。提供方文档声明时间为 America/New_York，分钟标签从 09:30 到 15:59 表示柱开始，成交量仅含 IEX，且只按拆股复权、不按分红或分拆复权。原 CSV 时间戳无时区偏移；本地来源凭证基于这些公开说明和文件 `source=iex` 字段作审阅记录，不是下载事件或版本校验和证明。

审计覆盖完整 XNYS 常规交易分钟：436,887 / 450,390（97.00%），低于项目 98% 门槛；790 个交易日低于 98%，单日覆盖中位数 97.18%。不补造 IEX 无成交分钟，也不使用任何插值。任何输入或目标窗口跨越缺失分钟都会被排除。提供方已记录 2024-12-23 数据截短，但本地文件该日有 59 行，止于 13:33 ET，与已知问题页记录的截短时间不一致，须保留此版本差异。

Clean 过滤使用居中 50 柱异常值窗口，未来邻柱可能影响历史柱是否保留，因此即使验证切分按时间排列，也不能把结果解释为严格因果分钟预测。该文件是 IEX 单一交易所成交记录，不是全美合并行情。质量审计、覆盖分布和网页证据哈希见 `audits/AAPL_clean_1min_quality.md` 与同名 JSON。仅当来源等其他门槛通过、唯一失败项为覆盖率时，才可用 `--exploratory-quality-limited` 运行开发诊断；不得做最终测试或报告正式排名。

优先用 `python download_data.py --symbol AAPL --interval 1d --refresh` 获取最新数据，再用 `--interval 1mo` 下载月线。本次 Yahoo 返回 HTTP 403，失败记录保留在 `AAPL_1d.download_failure.json`，没有把旧数据伪装成新数据。

复建与本次回归相同的旧缓存：

```bash
python prepare_regression_data.py
```

该入口固定镜像 commit `08ba60b568c300a635da1b6291a0f54eb9ef3f13`、原始和规范化 CSV 两种哈希，缺失／截断／变更会失败。它核实复现文件身份，**不等于核实原始行情、复权或来源可靠性**。下载网址、真实下载时间及旧数据限制保存在 sidecar。原 `/tmp` sidecar 的检索时间没有可靠证据，不继续当作真实检索记录。

分钟文件必须为一分钟 OHLCV、明确起始时间标记及 IANA 时区，正常交易分钟不应有日线级插值。覆盖率分母来自完整 XNYS 常规交易日历，含首尾全天和缺失整天；边界天不完整也应另行补全或明确裁剪。允许最多 2% 缺失并不意味着填补缺失：缺柱所在样本仍被排除。

时区未声明时，覆盖率仅是在 America/New_York 假设下的诊断值，不能证明时区或来源。即使此数值很高，日内数据门槛仍会因时区／来源未验证而拒绝训练。

`provenance.example.json` 仅是结构模板，无法直接通过验证。人工核实供应商原始文件、下载记录、时区、复权和时间标签后，凭证应记录真实 reviewer / source_url / review_evidence 与哈希。不要通过修改一个布尔值、来源文字或时区来“修复”无法验证的数据。
